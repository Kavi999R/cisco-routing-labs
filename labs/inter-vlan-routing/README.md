# Inter-VLAN Routing

## Overview

This lab demonstrates Inter-VLAN Routing using Cisco Packet Tracer. The objective is to allow devices in different VLANs to communicate through a router.

## Concepts Practised

* VLAN configuration
* Access ports and trunk ports
* 802.1Q encapsulation
* Router-on-a-stick
* Router subinterfaces
* Inter-VLAN connectivity testing

## Verification Commands

```cisco
show vlan brief
show interfaces trunk
show ip interface brief
show running-config
ping
```

## Learning Outcomes

This lab helped me understand how VLANs separate devices into different logical networks and how router-on-a-stick enables communication between those networks.
