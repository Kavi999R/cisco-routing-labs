# OSPF Routing

## Overview

This lab demonstrates dynamic routing using Open Shortest Path First (OSPF) in Cisco Packet Tracer.

The objective is to allow routers to exchange routing information and provide connectivity between different IP networks.

## Concepts Practised

* OSPF configuration
* OSPF process ID and router ID
* OSPF areas
* Neighbour relationships
* Dynamic route learning
* Routing table verification
* Network connectivity testing

## Verification Commands

```cisco
show ip ospf neighbor
show ip route
show ip protocols
show ip ospf interface
ping
```

## Learning Outcomes

This lab helped me understand how OSPF dynamically discovers routes, establishes neighbour relationships and shares routing information between routers.
