# Access Control Lists (ACL)

## Overview

This lab demonstrates the use of Access Control Lists (ACLs) in Cisco Packet Tracer to control network traffic and improve network security.

The objective is to allow or deny specific traffic based on defined network access rules.

## Concepts Practised

* Extended Access Control Lists
* Permitting and denying network traffic
* ACL rule ordering
* Applying ACLs to router interfaces
* Controlling wireless network access
* DHCP traffic permissions

## Configuration and Verification

The ACL was configured on the router to restrict wireless network access to selected internal networks while allowing permitted traffic.

Verification commands:

```cisco
show access-lists
show running-config
show ip interface brief
ping
```

## Learning Outcomes

This lab helped me understand how ACLs filter network traffic, how rule order affects access decisions, and how access restrictions can be applied to protect network resources.
